# Expense Splitter

Lite Splitwise for **Shivansh's Mini Apps** — create a group, log expenses, track balances, settle up.

## Stack

- Next.js + TypeScript + Tailwind
- Supabase Postgres (free tier)
- Vercel Hobby

## Local

```bash
cp .env.example .env.local
npm install
npm run dev
```
